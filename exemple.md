# Page d'exemple

Cette page sert à tester la navigation entre routes Docsify.

Quand vous ouvrez cette page, le plugin `docsify-robot-md` met à jour
la balise :

```html
<link rel="alternate" type="text/markdown" href=".../exemple.md">
```

Le Markdown brut de cette page est donc directement accessible aux
robots et aux lecteurs sans JavaScript.
